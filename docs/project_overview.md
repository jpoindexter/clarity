# Clarity - Project Overview

## Purpose & Vision

Clarity is a clean, AI-assisted research viewer designed to help users explore how different topics are framed across media sources. It offers search-driven insights using local language models to surface tone, manipulation risk, and source metadata. Inspired by tools like Elicit and Consensus, it focuses on delivering fast, structured answers to user queries without fluff or editorial bias.

## What Clarity Is Not

- Not a news reader
- Not a feed-scroller
- Not a finance report generator
- Not a social media aggregator

## Target Users

Clarity serves a wide spectrum of high-context users:
- Investigative journalists
- Media analysts
- Curious readers
- Researchers and students

The interface is designed for clarity, speed, and strategic analysis—not entertainment.

## MVP Scope

### Supported Modes:
- **Search** → Clean input-first experience

### AI Tagging Includes:
- Tone classification (supportive, neutral, critical)
- Manipulation markers (e.g., framing, contradiction)
- Optional insight tags (summarized AI rationale)

### Data Sources:
- Google News RSS (query-matched)
- GDELT + Common Crawl (optional)
- Curated RSS mesh (stable sources)
- No social media
- No user-submitted content

## Business Model

None for MVP. This is a research-grade prototype and portfolio product.

## Long-Term Potential

Future versions may support:
- Saved investigations
- Private knowledge graphs
- Enterprise white-label versions
