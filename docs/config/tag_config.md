# ⚙️ Tag Configuration System — Clarity

This document describes how tag configuration, suppression, styling, and overrides are managed for the Clarity platform.

---

## 🧠 Purpose

Clarity's tag system supports structured metadata (AgentTags) generated by AI agents. The configuration layer controls:

- Visual appearance (color, icon)
- Visibility (filtering, suppression)
- Client/domain overrides
- Ranking and prioritization

---

## 🧱 Color Mapping

Tags are assigned `color_key` values based on a combination of severity and type:

| Severity     | Type       | color_key example          |
|--------------|------------|----------------------------|
| critical     | signal     | severity:critical:signal   |
| medium       | emotional  | severity:medium:emotional  |
| low          | meta       | severity:low:meta          |

The frontend receives this `color_key` and maps it to a Tailwind-compatible color class or inline HSL value.

---

## 🔒 Suppression Rules

Tags may be suppressed by default if they meet any of the following:

- `confidence < MIN_CONFIDENCE` (default: 0.5)
- `importance < MIN_IMPORTANCE` (default: 30)
- Tag ID or type is in the client/domain blacklist

---

## 🪄 Client and Domain Overrides

Overrides cascade in this order:

1. Client-specific settings
2. Domain-level rules
3. Global defaults

### Override Examples

```yaml
# Example: Client A
overrides:
  contradiction:
    label: "⚠ Conflict"
    color_key: "severity:critical:signal"
    icon: "⚠️"
    client_visible: true
  sentiment:neutral:
    client_visible: false
```

---

## 📊 Ranking Strategy

Tag display order is determined by:

1. `importance` (0–100, descending)
2. `severity` rank (critical > high > medium > low > info)
3. Confidence (optional tiebreaker)

The processor sets a `display_rank` before sending tags to the UI.

---

## 🧪 Fallbacks

If a tag is returned without `color_key`, `label`, or `severity`:
- Assign default severity = "info"
- Assign color_key = "severity:info:unknown"
- Use `id` as label if label missing
- Render in a neutral gray chip with `?` icon
