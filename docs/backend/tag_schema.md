# 🧠 Clarity Backend — Tag Schema

This document defines the schema used to represent structured metadata tags (`AgentTag`) generated by AI agents and processed by Clarity’s backend.

---

## ✅ AgentTag Schema (v1)

```ts
interface AgentTag {
  id: string;                         // Unique identifier for the tag (e.g., "contradiction", "meta:longform")
  label: string;                      // Human-readable label to be displayed
  type: "emotional" | "signal" | "meta" | "custom";
  severity?: "critical" | "high" | "medium" | "low" | "info";
  importance?: number;               // Sort priority (0–100)
  confidence?: number;               // Optional: Float between 0.0 and 1.0
  source?: string;                   // Originating agent or pipeline
  icon?: string;                     // Optional: emoji or icon slug
  color_key?: string;                // Optional: derived color category (used for styling)
  client_visible?: boolean;          // Optional: if false, tag is suppressed from UI
  raw_value?: any;                   // Original agent output, for traceability/debugging
}
```

---

## 🧱 Required Fields

| Field  | Required | Notes |
|--------|----------|-------|
| `id`   | ✅        | Must be globally unique and consistent |
| `label` | ✅       | Must be clear, concise, and user-facing |
| `type` | ✅        | Controls grouping and display logic |

---

## ❓ Optional Fields & Usage

- `severity`: Used to prioritize tag importance and apply color styling.
- `importance`: Ranks tags within a card.
- `confidence`: Used for filtering and suppression.
- `color_key`: Mapped to frontend style definitions.
- `client_visible`: If false, tag is hidden in UI but stored.
- `raw_value`: Used for audits, explanation overlays, or future retraining.

---

## 🔄 Tag Standardization

All agent outputs must pass through a Tag Processor that:

1. Validates schema conformity
2. Adds missing defaults (e.g., severity = info)
3. Computes `color_key` from `(type + severity)`
4. Applies client/domain overrides
5. Outputs a normalized, display-ready `AgentTag[]`

---

## 🧪 Schema Versioning

This schema is versioned per major Clarity release. Future extensions (e.g. tag relationships, expiry, nested tags) must maintain backward compatibility with v1 processors.
